# Night Drift

Аркадная 3D-гонка с дрифтом на ночной неоновой трассе. Можно ездить одному или онлайн с друзьями: до 6 игроков в комнате, 3 круга, общий старт.

## Структура

```
public/                    игра (статичный сайт)
  index.html               разметка и стили
  config.js                адрес онлайн-сервера
  js/main.js               запуск, игровой цикл, пауза и старт
  js/state.js              общее состояние игры и онлайна
  js/game.js               очки дрифта, удары о стену, круги
  js/player.js             машина игрока
  js/core/physics.js       физика машины, stepCar() — заморожена, см. «Проверки»
  js/core/render.js        рендер, сцена, камера, небо, свет
  js/core/carModel.js      3D-модель машины
  js/core/fx.js            следы шин и дым
  js/core/input.js         клавиатура и сенсорные кнопки
  js/core/audio.js         звук мотора и резины
  js/core/cameraRig.js     сглаживание камеры
  js/modes/track/          режим «Дрифт-трасса»: геометрия, декорации, камера, HUD
  js/modes/traffic/        режим «Трафик» (в разработке): шоссе, камера сверху, трафик
                           (sim.js — симуляция ботов без three.js, её же будет запускать сервер)
  js/net/net.js            онлайн: комнаты, часы, предсказание соперников, столкновения
  js/ui/hud.js             вспомогательные функции HUD и меню
server/                    мультиплеерный сервер на Colyseus (Node.js)
tests/                     проверки физики и синхронизации
netlify.toml               настройки для Netlify
vercel.json                настройки для Vercel
render.yaml                настройки сервера для Render
```

**Режим «Трафик» в разработке.** Пока его можно открыть только по адресу с `?mode=traffic`, например `http://localhost:2567/?mode=traffic`. Сейчас там бесконечное шоссе на 4 полосы с отбойниками, камерой сверху и трафиком: легковушки, фургоны, фуры и автобусы держат дистанцию, тормозят и перестраиваются с поворотником. Столкновения работают: задел бота бортом или догнал его чуть быстрее — он тормозит и мигает аварийкой, а влетел в него сзади на скорости (больше 32 км/ч разницы, в борт — больше 50) — авария и экран итогов. Если бот сам въехал в тебя сзади, это всегда лёгкий удар. Очки, онлайн и выбор режима в меню — следующие этапы.

**Режимы.** Всё, что зависит от того, где едет машина, живёт в режиме (`js/modes/…`). Каждый кадр игра вызывает `stepCar()` — одну и ту же физику для всех режимов, — а затем `mode.constrain()`: стены, съезд с трассы, круги. Камера, HUD и расстановка на старте тоже принадлежат режиму. Новый режим «Трафик» будет устроен так же.

## Как устроен мультиплеер

- **Сервер решает всё, что влияет на результат:** кто в комнате, когда старт, время кругов, порядок финиша, итоги. Время кругов меряет сервер по своим часам, поэтому подделать его на компьютере игрока нельзя.
- **Общий старт.** Игра сверяет часы с сервером, и все отсчитывают «3, 2, 1» до одного и того же серверного момента. Машины стартуют одновременно с точностью до нескольких миллисекунд.
- **Своя машина без задержки.** Физика вашей машины считается у вас, поэтому управление не лагает. Позиция отправляется на сервер 30 раз в секунду вместе с меткой времени по общим часам.
- **Соперники там, где они сейчас.** Каждое обновление идёт по сети с задержкой (пинг). Игра знает, насколько оно устарело, и сдвигает машину соперника вперёд по её скорости и повороту на это время. Небольшие поправки сглаживаются за ~0,1 с, поэтому машины не дёргаются. В тесте с пингом 300 мс и нестабильной связью соперник отображается в среднем в 1 м от своей реальной позиции. Без предсказания он отставал бы на 10–11 м.
- **Пинг на экране.** В режиме онлайн под временем круга показан пинг до сервера. Если он выше 180 мс, цифра становится красной: сервер слишком далеко.
- **Столкновения.** Каждая машина — это два перекрывающихся круга (перед и зад), которые точно повторяют вытянутую форму кузова. Каждый игрок считает удар для своей машины по предсказанной позиции соперника и через сервер передаёт сопернику его долю удара. Кто первым заметил контакт, тот его и засчитывает; повторное срабатывание в течение 0,3 с отбрасывается, поэтому удар никогда не применяется дважды. Удар толкает и закручивает машину по законам сохранения импульса (одинаковые массы, упругость 0,3). Машина соперника на вашем экране реагирует на удар сразу, не дожидаясь ответа по сети. Сервер проверяет, что машины действительно были рядом, и ограничивает силу удара.
- **Защита от явного читерства.** Сервер отбрасывает телепорты и невозможно быстрые круги (быстрее 20 секунд).
- **Обрыв связи.** Если соединение пропало, игра сама переподключается в течение 20 секунд.

Одна Wi-Fi-сеть не нужна: играть можно из разных городов.

## Запуск на своём компьютере

Нужен [Node.js](https://nodejs.org/) 18 или новее.

```bash
cd server
npm install
npm start          # сервер на ws://localhost:2567
```

В другом окне терминала из корня репозитория:

```bash
npx serve public   # игра на http://localhost:3000
```

Откройте игру в двух вкладках, в одной создайте комнату, в другой войдите по коду. На localhost игра сама подключается к локальному серверу.

Игра состоит из ES-модулей, поэтому `index.html` нельзя открыть двойным щелчком: браузер не загрузит модули с `file://`. Всегда открывайте игру через сервер (`npx serve public` или `npm start` в `server`).

## Проверки

Нужен Node.js 18+. Один раз в корне репозитория: `npm install` (и `npm install` в папке `server` для проверки онлайна).

```bash
npm test             # физика: 3 минуты езды должны совпасть с записью до бита
npm run test:sync    # онлайн: два игрока в Chrome через пинг ~150 мс
```

**Физика заморожена.** `tests/fixtures/physics-golden.json` — запись езды на исходной версии игры (коммит `06ee674`): дрифты, задний ход, удары о стены, три круга, неровная частота кадров. Запись сделана скриптом `tests/tools/make-golden.mjs`, который вырезает физику прямо из того коммита. `npm test` гоняет тот же маршрут через текущий код и требует совпадения каждой позиции и скорости до последнего бита. Если тест упал, машина ведёт себя иначе, чем раньше.

**Синхронизация.** `npm run test:sync` запускает сервер и прокси, который добавляет пинг ~150 мс с разбросом, открывает двух игроков в Chrome. Игрок A въезжает в B (удар должен дойти до B), затем 20 секунд ездит по трассе, а тест на каждом кадре сравнивает, где B видит машину A и где она на самом деле. Тест падает, если удар не дошёл или расхождение выросло. Запускайте его после каждого изменения, которое касается онлайна. Если Chrome установлен не в стандартное место: `CHROME_PATH=/путь/к/chrome npm run test:sync`.

## Деплой

Нужны два места: **сервер** (постоянно запущенный Node.js) и **сайт с игрой**. Netlify и Vercel подходят только для сайта: держать постоянное WebSocket-соединение они не умеют.

### 1. Сервер на Render

1. Зайдите на [render.com](https://render.com) через GitHub.
2. **New → Blueprint**, выберите этот репозиторий. Render прочитает `render.yaml` и создаст сервис `night-drift-eu` в регионе Frankfurt.
3. После деплоя откройте адрес вида `https://night-drift-eu.onrender.com`: сервер сразу отдаёт и саму игру, и мультиплеер. Отдельный хостинг для сайта не обязателен.

**Регион важен.** Выбирайте регион сервера ближе к игрокам: для Узбекистана и СНГ это **Frankfurt (EU Central)**, пинг около 80–120 мс против ~300 мс до Oregon. Регион существующего сервиса на Render поменять нельзя, поэтому для смены нужно создать новый сервис.

На бесплатном тарифе Render усыпляет сервер после 15 минут без игроков. Первое подключение после этого может занять до минуты. Если это мешает, подойдёт платный тариф Render или другой хостинг для Node.js: Railway, Fly.io, любой VPS. Команда запуска везде одна: `npm install && npm start` в папке `server`, порт берётся из переменной `PORT`.

### 2. Адрес сервера в игре

Откройте `public/config.js` и впишите адрес сервера, заменив `https://` на `wss://`:

```js
window.NIGHT_DRIFT_SERVER = 'wss://night-drift-server.onrender.com';
```

Закоммитьте и запушьте изменение.

### 3. Сайт на Netlify или Vercel

- **Netlify:** Add new site → Import an existing project → этот репозиторий. Настройки подтянутся из `netlify.toml`, ничего менять не нужно.
- **Vercel:** Add New → Project → этот репозиторий, Framework Preset: Other. Папку `public` Vercel возьмёт из `vercel.json`.

После деплоя откройте сайт, нажмите «Онлайн с друзьями», создайте комнату и отправьте друзьям ссылку из лобби.

## Управление

| Клавиши | Действие |
|---|---|
| `W` / `↑` | газ |
| `S` / `↓` | тормоз и задний ход |
| `A` `D` / `←` `→` | руль |
| `Пробел` | ручник, срыв в занос |
| `R` | вернуться на трассу |
| `P` | пауза (только в одиночном заезде) |
| `M` | звук вкл/выкл |

На телефоне появляются сенсорные кнопки.

## Очки дрифта

- Очки идут, пока машина едет боком по асфальту: чем больше угол и скорость, тем больше.
- Длинный непрерывный занос поднимает множитель до ×5.
- Удар о стену сжигает очки текущего заноса.

## Технологии

- [Three.js](https://threejs.org/) r128: 3D-графика
- [Colyseus](https://colyseus.io/) 0.15: комнаты, синхронизация состояния, переподключение. Клиентская библиотека закреплена на 0.15.27, потому что в 0.15.28 браузерная сборка сломана.
- Web Audio API: звук мотора и резины, сгенерированный кодом
