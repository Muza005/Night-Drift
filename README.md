# Night Drift

Аркадная 3D-гонка с дрифтом на ночной неоновой трассе. Работает прямо в браузере, без установки и сборки.

## Как запустить

Откройте `index.html` в любом современном браузере. Нужен интернет: Three.js и шрифты загружаются с CDN.

Чтобы играть по ссылке, включите GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.

## Управление

| Клавиши | Действие |
|---|---|
| `W` / `↑` | газ |
| `S` / `↓` | тормоз и задний ход |
| `A` `D` / `←` `→` | руль |
| `Пробел` | ручник, срыв в занос |
| `R` | вернуться на трассу |
| `P` | пауза |
| `M` | звук вкл/выкл |

На телефоне появляются сенсорные кнопки.

## Как набирать очки

- Очки идут, пока машина едет боком по асфальту: чем больше угол и скорость, тем больше.
- Длинный непрерывный занос поднимает множитель до ×5.
- Удар о стену сжигает очки текущего заноса.
- Лучшее время круга сохраняется в браузере.

Совет: перед поворотом дайте руль, коротко дёрните ручник и сразу жмите газ, а угол ловите контррулём.

## Технологии

- [Three.js](https://threejs.org/) r128: графика
- Web Audio API: звук мотора и резины, сгенерированный кодом
- Всё в одном файле `index.html`
