# 3D-модели машин

Кандидаты на замену машин игроков в Night Drift. Все файлы — glTF, их читает three.js.

| Файл | Машина | Треугольников | Размер | Заметки |
|---|---|---|---|---|
| `muscle_car.glb` | Футуристичный маслкар (LagzDesign, «Generic Futuristic muscle car» 1.1) | 29 тыс. | 2,9 МБ | Собран из OBJ + MTL + текстур шин и дисков, бывших в архивах blend/fbx/obj |
| `nissan_gtr_r32.glb` | Nissan Skyline GT-R R32 | 6,7 тыс. | 0,45 МБ | Раньше назывался `fbx.glb` |
| `lowpoly_stylized_rx_7_free.glb` | Mazda RX-7, лоу-поли | 4,2 тыс. | 0,21 МБ | |
| `sports_car.glb` | Суперкар в духе Lamborghini | 4,3 тыс. | 0,77 МБ | |
| `everest.gltf` | Раллийный хэтчбек с антикрылом | 6,8 тыс. | 0,33 МБ | Нет двух текстур, на которые он ссылается: `e4c3c84ae9634e20b657ef68d2d85450_RGB_Color_1_Tex.png` и `302e693ddb2a4dddbd108beeb46ec33d_RGB_internal_ground_ao_texture.jpeg` |
| `nexus_rx.glb` | Nexus RX, концепт-седан с салоном | 201 тыс. | 22 МБ | Очень тяжёлый для игры; все материалы помечены полупрозрачными, кузов надо делать непрозрачным |

Исходные архивы маслкара (Blender, FBX, OBJ, текстуры и описание) остались в истории ветки,
в коммите 675c893.

Модели загружены с Fab / Sketchfab. Перед публикацией игры проверьте лицензию каждой
(часто это CC BY: нужно указать автора и ссылку).
