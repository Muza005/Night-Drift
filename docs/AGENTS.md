# Агенты Claude Code для Night Drift

В проекте есть пять специализированных агентов (субагентов Claude Code). Каждый отвечает за свою часть игры, знает её файлы и правила и сам прогоняет нужные тесты.

Описания агентов лежат в `.claude/agents/`. Claude Code подхватывает их автоматически, когда сессия открыта в папке проекта.

| Агент | Чем занимается | Его файлы |
|---|---|---|
| `nd-maps` | Карты и движок трасс: геометрия, бордюры и стены, высоты, мосты, уклоны, прыжки на гребнях, срезки, мини-карта, чертежи карт, валидатор карт | `public/js/modes/track/`, `tests/maps.test.mjs` |
| `nd-ui` | Интерфейс: главный экран, гараж и стенд, лобби, выбор карты, итоги, HUD, иконки, фон меню, токены, доступность, телефон | `public/index.html`, `public/css/`, `public/js/ui/`, UI-тесты |
| `nd-physics` | Поведение машин: столкновения, массы, подброс от удара, обочины, реакция на уклоны и приземление, камера при разгоне, дым, баланс машин | `net/net.js` (удары), `modes/traffic/collide.js`, `modes/traffic/geometry.js`, `core/fx.js`, `core/cars.js` |
| `nd-net` | Онлайн: сервер Colyseus, сообщения комнаты (карта, настройки, удары), отправка и предсказание позиций, задержки, тест синхронизации | `server/src/index.js`, `net/net.js` (сеть), `tests/server-*`, `tests/sync/` |
| `nd-qa` | Проверка после этапа: все тесты, экраны и онлайн в браузере, ревью изменений. Ничего не меняет, только присылает список проблем | — |

## Общие правила

Они прописаны в каждом агенте:
- **`core/physics.js` (`stepCar`) не меняется**, и его «золотой» тест совпадает бит в бит. Новое поведение — вокруг него.
- **Сначала замер, потом правка.** Цифры «до/после» — в отчёте.
- **Браузерные тесты** — с `--headed` (на видеокарте), на своём порту и с `?server=ws://localhost:PORT`.
- **Пороги тестов не ослабляются**, чтобы тест прошёл.

## Как пользоваться

**Попросить в обычной сессии Claude Code:**
> Пусть агент nd-maps сделает этап 4 из docs/PLAN-2.md

> Запусти nd-qa на последний коммит

Главная сессия (координатор) запускает агента, получает его отчёт и пересказывает вам. Коммиты, push и PR делает координатор.

**Посмотреть или изменить агентов:** команда `/agents` в Claude Code или правка файлов `.claude/agents/*.md`.

## Как они работают вместе

- **Последовательно по умолчанию.** Агенты правят одни и те же файлы (например, `net/net.js` нужен и `nd-physics`, и `nd-net`). Поэтому этапы идут по очереди: агент → `nd-qa` → правки → коммит.
- **Параллельно — только для независимых частей.** Например, `nd-ui` делает фон меню, пока `nd-maps` строит карту. Тогда каждый работает в своей копии репозитория (git worktree), а координатор сливает результаты.
- **Каждый запуск начинается с чистого листа.** Агент не помнит прошлый разговор, всё нужное он читает из плана и кода. Поэтому задача формулируется со ссылкой на этап плана.
- **Агенты стоят дороже**, чем работа в одной сессии: каждый заново читает код. Мелкие правки быстрее делать без них.

## Кто ведёт этапы плана (`docs/PLAN-2.md`)

| Этап | Агент | Проверка |
|---|---|---|
| 1. Быстрые правки | `nd-physics` (обочина, камера, дым), `nd-ui` (шестерёнка), `nd-maps` (разметка) | `nd-qa` |
| 2. Загрузка машин, колёса Rally | `nd-ui` | `nd-qa` |
| 3. Фон меню | `nd-ui` | `nd-qa` |
| 4. Движок трасс v2 | `nd-maps` + `nd-physics` (уклоны, прыжки) | `nd-qa` |
| 5. Новые карты | `nd-maps` | `nd-qa` |
| 6. Выбор карты | `nd-ui` + `nd-net` (поле `map` на сервере) | `nd-qa` |
| 7. Слипстрим | `nd-physics` | `nd-qa` |
| 8. Столкновения | `nd-physics` | `nd-qa` |
| 9. Синхронизация | `nd-net` | `nd-qa` |
| 10. Финал | `nd-qa`, затем координатор | — |
