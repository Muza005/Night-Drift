# Прогресс плана №2 (автопилот)

Этот файл ведёт координатор (главная сессия Claude Code). По нему автопилот продолжает работу после паузы: лимит, перезапуск. План — `docs/PLAN-2.md`, роли агентов — `docs/AGENTS.md`.

**Правила автопилота:**
- **Ветка:** `fixes-and-maps`. После каждого этапа — коммит и push. В `main` не сливаем, на Render не деплоим.
- **Цикл этапа:**
  1. агент роли делает этап;
  2. `nd-qa` проверяет;
  3. координатор исправляет найденное;
  4. `npm test` и браузерные тесты с `--headed` (без окон);
  5. коммит, push;
  6. мини-отчёт в чате со скриншотами.
- **Браузеры — только без окон** (headless на видеокарте).
- **PR:** https://github.com/Muza005/Night-Drift/pull/27 — обновляется сам с каждым push.
