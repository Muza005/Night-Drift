# Прогресс плана №2 (автопилот)

Этот файл ведёт координатор (главная сессия Claude Code). По нему автопилот продолжает работу после паузы: лимит, перезапуск. План — `docs/PLAN-2.md`, роли агентов — `docs/AGENTS.md`.

**Правила автопилота:**
- **Ветка:** `fixes-and-maps`. После каждого этапа — коммит и push. В `main` не сливаем, на Render не деплоим.
- **Цикл этапа:**
  1. агент роли делает этап;
  2. `nd-qa` проверяет;
  3. координатор исправляет найденное;
  4. `npm test` и браузерные тесты с `--headed` (без окон);
  5. коммит, push;
  6. мини-отчёт в чате со скриншотами.
- **Браузеры — только без окон** (headless на видеокарте).
- **PR:** https://github.com/Muza005/Night-Drift/pull/27 — обновляется сам с каждым push.

## Этап 8

- Удар решает один игрок (более быстрая машина), каждая машина получает ровно один толчок. Отскок 0,1, трение кузовов, вращение не больше 2 рад/с, подскок от 80 км/ч сближения. Логика — `net/bump.js`, сценарий замеров — `npm run test:hits -- [old|new] [map]`.
- Проверка после паузы (nd-qa): все тесты на уровне этапа 7 или выше, ничего не сломалось.
- По итогам QA: сервер больше не пропускает подброс и вращение без настоящего удара; окно «оба решили удар» учитывает пинг; убраны остатки старого кода.
- Для этапа 9: сервер верит заявленной скорости машин (до ±80 м/с). Проверка скорости по истории позиций — там.

## Этап 9

- Положение машины сервер пересылает сразу (`'st'`, `net/statecodec.js`), без ожидания патчей схемы. Отправка ровная: 40 раз в секунду рядом с другой машиной, 30 иначе.
- Чужая машина сглаживается пружиной (`net/ghostsync.js`), при ударе прижимается к вашей, а не выталкивается из неё каждый кадр. Рывок после удара: 0,30–0,50 → 0,12–0,22 м; у того, в кого врезались, 2,7–3,9 → 0,20–0,27 м.
- Сервер сверяет заявленную скорость с тем, как машина двигалась. По итогам QA: шаги быстрее любой машины (прыжки позиции, в том числе мелкие частые) в расчёт скорости не попадают, скорость удара не больше 80 м/с; сдвиг при выталкивании ограничен 6 м; окно `?debug=net` внизу слева.
- Отклонено от плана осознанно: 30 отправок в секунду вдали (не 20) и без буфера задержки — это ухудшило бы точность.
