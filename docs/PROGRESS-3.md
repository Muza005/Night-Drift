# Прогресс плана №3 (автопилот)

Файл ведёт координатор (главная сессия Claude Code). По нему автопилот продолжает работу после паузы. План — `docs/PLAN-3.md`, роли — `.claude/agents/nd-*.md`.

**Две дорожки параллельно:**

| Дорожка | Ветка | Папка | Порты агентов |
|---|---|---|---|
| Физика и синхронизация (этапы 0–6) | `physics-and-sync` | `/home/proser/Downloads/Night-Drift` | 4100–4199 |
| Меню (U0–U5) | `menu-redesign` | `/home/proser/Downloads/Night-Drift-menu` (git worktree) | 4200–4299 |

**Правила:**
- Цикл этапа: агент роли → `nd-qa` → координатор исправляет → `npm test` и браузерные тесты с `--headed` → коммит и push в ветку дорожки → мини-отчёт в чате со скриншотами.
- В `main` не сливаем, на Render не деплоим. Порты 3000 и 2567 не трогаем. Браузеры только без окон; у `playwright-cli` флаг `--headed` не используем.
- Остановки для пользователя: после U1 (выбор направления меню), этап 6 (настройка «на ощупь»), `superdesign` — только с согласия.
- Таймер: раз в час координатор проверяет агентов и продолжает работу.
