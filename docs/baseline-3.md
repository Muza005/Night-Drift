Что видно:
- Удар 90° на 90 км/ч отбрасывает на 3,2–3,6 м (цель этапа 3 — меньше 1 м), на 180 км/ч — на 7,8–8,2 м: отскок 0,45 от скорости в стену.
- Для сравнения без стены накатом: 180 → 177 км/ч за 0,1 с, → 163 за 0,5 с; 90 → 78 за 0,5 с.
- 45° на 180 км/ч: через 0,1 с 113–115 км/ч (цель 90–120 — уже в ней). Касание 15° на 180: 140 км/ч через 0,1 с против 177 без стены — потеря ~21 % (цель 5–10 %): отскок разворачивает скорость от стены, нос ещё смотрит в стену, и шины гасят этот боковой занос.
- **Удар прямо в стену (и касание носом на 5 км/ч) за один подшаг поворачивает машину на 22,5–25,7°.** `wallAlign` при носе точно в стену получает направление «вдоль стены» нулевой длины, `atan2(0, 0)` даёт мировой угол 0, и машина доворачивается к нему на четверть. Отсюда боковой сдвиг после прямого удара (−1…−1,8 м) — то самое «медленный удар сдвигает вбок».

## Удары машин (`npm run test:walls`, вторая таблица)

Купе против купе (масса 1,0), обе на одном компьютере: быстрая решает удар (`net/bump.js collideStep`), второй её доля приходит сразу. A бьёт, B стоит. Без газа, кроме толкания (у A газ в пол).

Что видно:
- Наезд сзади точно по оси: сразу после удара B ≈ 99, A ≈ 81 км/ч (сохранение импульса при отскоке 0,1), бокового ухода нет — у двух кругов при соосном ударе его и не бывает. Сдвиг вбок появится при смещении — это сценарий `npm run test:hits`.
- Удар боком на 60 км/ч: B уезжает на 3,1 м за 0,5 с (цель этапа 4 — до 1,5 м) и поворачивается на 31°.
- «Ненулевых импульсов» — подшаги, в которые удар менял скорости. Удар боком: 2 импульса, дальше 59 подшагов в контакте только выталкивание.
- **Толкание — фикция скоростей.** Ограничение «один контакт отдаёт не больше, чем дала скорость сближения» (`epCap`) исчерпывается за 53 подшага (0,44 с), а контакт не кончается. Дальше машины двигает только выталкивание: обе едут вместе ~26 км/ч (зазор 4,40 м не меняется), а спидометр A показывает 63 км/ч, B — 12.

## Скан карт (`npm run scan:maps`)

Земля: `y = −0,02` на картах с высотами, `0` на плоских (scene.js). Полосы асфальта, бордюра и обочины — плоские треугольники, поэтому проверяются их углы: это точно для каждой точки полосы. Стены: луч из каждой точки трассы и каждой точки срезки в обе стороны; стена для столкновений **измерена** самим `constrainToTrack` (точка, откуда стоящую машину выталкивает), к ней прибавлен запас 1,25 м по нормали стены в этой точке (направление выталкивания; вдоль луча это 1,25 / cos φ) — «где касается кузов»; нарисованная — те же линии, по которым scene.js строит стены (`wall-lines.js drawnWalls`). Лучи, которые встречают стену под cos φ < 0,2, не оцениваются (на всех картах таких 0).

## Въезд в срезки (`npm run test:walls`, третья таблица)

Скриптовый водитель (купе) едет через каждую срезку: 40 точек трассы до устья, срезка, 25 точек после. Пять линий: середина; края (бок машины на краю асфальта: центр в `half − 1` = 1,5 м от середины); бордюры (бок на внешнем краю бордюра: центр в 2,0 м, предел центра 2,15 м). Смещение набирается на первых 8 м срезки и снимается на последних 8 м. Скорость — та, что позволяет самый крутой изгиб этой линии (70 % поворота на полном руле). На картах без срезок (Ночной город, Эстакада, Паркинг, Перевал) — нечего ехать.
